# Книговёрт

Приложение для Windows, которое превращает книги и документы из одного формата в другой и собирает главы из разных файлов в одну книгу. Работает без интернета: файлы не покидают компьютер.

## Что умеет

**Конвертация.** Любой поддерживаемый формат в любой другой, можно сразу несколько файлов.

| Читает | Сохраняет |
| --- | --- |
| FB2 и FB2 в архиве (.fb2.zip) | FB2 и FB2 в архиве |
| DOCX | DOCX |
| PDF | PDF |
| EPUB | EPUB |
| TXT | TXT |
| HTML | HTML |
| Markdown | Markdown |

При конвертации сохраняются главы и их вложенность, жирный текст и курсив, сноски, картинки, таблицы, списки, стихи, цитаты, название, автор и обложка.

**Сборка книги.** Добавьте файлы в любых форматах, и их главы появятся одним списком. Дальше можно:

- менять порядок глав перетаскиванием или кнопками;
- объединять главы и делить одну главу на две в любом месте текста;
- переименовывать, удалять и делать главы подглавами;
- читать любую главу прямо в приложении;
- отменять любое действие;
- задать название, автора и обложку и сохранить результат в нужном формате.

Если вся книга собрана из PDF, страницы можно склеить как есть, без перевёрстки. Закладки появятся автоматически.

**PDF** получается книжным: переносы слов, оглавление с номерами страниц, закладки, титульная страница и встроенные шрифты с кириллицей и казахскими буквами. Размер страницы и шрифта выбираются при сохранении.

## Как запустить

### Готовое приложение

1. Скачайте архив `Knigovert-…-windows-x64.zip` со страницы [последнего релиза](https://github.com/Hashick1812/knigovert/releases/latest).
2. Распакуйте его в любую папку. Прямо из архива программа не запустится.
3. Откройте `Knigovert\Knigovert.exe`.

Python и интернет для запуска не нужны. Папку `Knigovert` можно скопировать на другой компьютер.

Программа не подписана сертификатом, поэтому Windows может показать предупреждение SmartScreen. Чтобы запустить её, нажмите «Подробнее», затем «Выполнить в любом случае».

Проверено на 64-битной Windows 11. Окно использует движок WebView2, который уже есть в Windows 11 и в обновлённой Windows 10. Если его нет, приложение откроется в браузере и завершится само через несколько минут после закрытия вкладки.

### Из исходников

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .
python -m knigovert
```

### Сборка .exe

```bash
pip install -e .[dev]
pyinstaller knigovert.spec --noconfirm
```

Готовая программа появится в папке `dist\Knigovert`.

## Что важно знать

- **Скан без текста.** Если в PDF страницы сохранены картинками, текст не распознаётся. Такие страницы переносятся картинками, и приложение об этом предупреждает.
- **PDF → другой формат.** В PDF нет настоящей структуры, поэтому абзацы и главы восстанавливаются по шрифтам, отступам и закладкам. Обычные книги читаются хорошо, а сложная вёрстка в несколько колонок может потребовать правки.
- **Старые форматы.** `.doc`, `.rtf` и `.odt` нужно сначала пересохранить в `.docx`.
- **Сноски в TXT и PDF.** При чтении этих форматов сноски остаются обычным текстом в конце книги.

## Где что лежит

| Путь | Что там |
| --- | --- |
| `src/knigovert/model.py` | Единая модель книги: все форматы читаются в неё и пишутся из неё |
| `src/knigovert/formats/` | Чтение и запись форматов |
| `src/knigovert/library.py` | Сборка книги из глав |
| `src/knigovert/server.py` | Локальный сервер интерфейса, доступен только с этого компьютера |
| `src/knigovert/web/` | Интерфейс |
| `tests/` | Тесты, в том числе все пары форматов |

Запуск тестов:

```bash
pip install -e .[dev]
pytest
```
